# Employee Call Quality & Performance Dashboard

## Project Overview

The Employee Call Quality & Performance Dashboard is a Power BI project designed to analyze call center operations and employee performance. It provides a visual overview of call volumes, answered and abandoned calls, answer rates, answer speed, and average talk duration to support data-driven decision-making.

## Objectives

* Monitor incoming, answered, and abandoned calls.
* Analyze employee-level call performance.
* Track key performance indicators (KPIs).
* Identify trends and areas for operational improvement through visualizations.

## Tools & Technologies

* **Power BI Desktop** — Dashboard development and data visualization
* **Microsoft Excel** — Data preparation and cleaning

## Key Performance Indicators (KPIs)

* Total Incoming Calls
* Total Answered Calls
* Total Abandoned Calls
* Average Answer Rate
* Average Answer Speed
* Average Talk Duration

## Dashboard Features

* KPI cards for an overview of call center performance.
* Employee-wise incoming call analysis.
* Comparison of answered and abandoned calls by employee.
* Employee-level answer rate visualization.
* Interactive visual reporting to support performance monitoring.

## Key Insights

The dashboard is designed to help users examine call volumes, compare employee-level results, monitor answer rates, and identify potential service-quality improvement areas.
